# Products Page

React + Vite + TypeScript, TanStack React Query, shadcn/ui, Tailwind CSS.

## Features
- Products grid using shadcn/ui Card
- Fetching and caching with React Query
- Search using `/products/search` (debounced)
- Pagination using `limit` / `skip`
- Product details page fetched by ID
- Loading, error, and empty states

## Run
npm install
npm run dev

## Check
npm run lint
npm run build
